Document Upload Flow
1
Patient uploads document in portal
2
Document saved with IsPatientUploaded = true
3
System creates a message in the patient's conversation with clickable file link
4
Conversation moves to top of all clinic staff's message list with unread badge
5
Staff clicks → sees notification → clicks link to view/download the file
No separate notification system. The message IS the notification. Same read/unread tracking per user.
